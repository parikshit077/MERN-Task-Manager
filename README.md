MERN Task Manager
A full-stack Task Management application built using the MERN stack (MongoDB, Express, React, Node.js). This project was developed as part of my BCA (Hons) curriculum to demonstrate full CRUD (Create, Read, Update, Delete) functionality and responsive web design.

🚀 Features
Full-Stack Architecture: Separated frontend and backend for better scalability.

CRUD Operations: Users can create, view, update, and delete tasks in real-time.

Responsive UI: Centered and mobile-friendly interface built with React.

Database Integration: Powered by MongoDB for persistent data storage.

🛠️ Tech Stack
Frontend: React.js, CSS

Backend: Node.js, Express.js

Database: MongoDB

Version Control: Git & GitHub

📂 Project Structure

⚙️ Installation
To run this project locally, clone the repository and install the dependencies:

Bash
# Clone the repository
git clone https://github.com/parikshit077/MERN-Task-Manager.git

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
